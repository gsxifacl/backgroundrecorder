# 🖥️ 电脑本地编译 APK 环境搭建教程（Windows → WSL2 路线）

> 结论先行：Windows 上**无法直接**用 buildozer 打包，必须借助 WSL2（微软官方的 Windows 内置 Linux 子系统）。
> 总共要装 3 层东西：WSL2/Ubuntu → 编译工具链 → buildozer（它会自动下载 Android SDK/NDK）。
> 预计占用磁盘 15GB 左右，首次构建 30~60 分钟（大头是下载 SDK/NDK，约 3~5GB）。

---

## 第 1 层：安装 WSL2 + Ubuntu

1. 以**管理员身份**打开 PowerShell（开始菜单右键 → 终端(管理员)）
2. 执行：
   ```powershell
   wsl --install -d Ubuntu-22.04
   ```
3. 完成后**重启电脑**，首次打开 Ubuntu 会让你设置用户名和密码（随便设，记住密码）
4. 验证：PowerShell 里执行 `wsl --status` 能看到版本 2 即成功

> ⚠️ 如果报错提示「虚拟化未启用」，需进 BIOS 打开 Intel VT-x / AMD-V。
> ⚠️ 如果提示需要更新 WSL：执行 `wsl --update`。

## 第 2 层：在 Ubuntu 里装编译工具链

打开 Ubuntu 终端（开始菜单搜 Ubuntu），依次执行：

```bash
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip python3-venv \
    autoconf libtool pkg-config zlib1g-dev libncurses-dev cmake \
    build-essential ccache
```

## 第 3 层：安装 buildozer

```bash
python3 -m pip install --upgrade pip
python3 -m pip install --user buildozer cython==0.29.36

# 把 buildozer 加进 PATH
echo 'export PATH=$PATH:~/.local/bin' >> ~/.bashrc
source ~/.bashrc

# 验证
buildozer --version
```

## 第 4 步：编译

```bash
# 项目在 Windows 的 D 盘，WSL 里通过 /mnt/ 访问
cd /mnt/d/workbudygszo/phone-recorder-app

buildozer android debug
```

- 首次运行会自动下载 Android SDK、NDK、平台工具（约 3~5GB，需要网络稳定）
- 完成后 APK 在项目的 `bin/` 目录：`backgroundrecorder-1.0-arm64-v8a-debug.apk`
- 传到手机安装即可（见「手机安装APK教程.md」第 7 步）

## 之后的日常构建

环境装好后，以后改了代码只需：

```bash
wsl                                # 进入 Ubuntu
cd /mnt/d/workbudygszo/phone-recorder-app
buildozer android debug            # 重新出包，几分钟即可
```

## 备选方案：Docker（不想折腾 WSL 内部环境的话）

如果电脑已装 Docker Desktop（其本身也依赖 WSL2），可以一条命令用现成镜像编译，免去第 2、3 层：

```powershell
cd D:\workbudygszo\phone-recorder-app
docker run --rm -v "${PWD}:/home/user/hostcwd" kivy/buildozer android debug
```

APK 同样出现在 `bin/` 目录。

## 常见报错

| 报错 | 解决 |
|---|---|
| `wsl --install` 说找不到包 | 先 `wsl --update`，或从微软商店手动装 "Ubuntu 22.04" |
| 构建中途下载 SDK 失败/超时 | 网络问题，重跑 `buildozer android debug` 会断点续传 |
| Java 版本不对 | 确认装的是 openjdk-17：`java -version` |
| 提示 cython 版本错误 | 必须是 `cython==0.29.36`（p4a 兼容版本） |
| 编译成功但 APK 装不上 | buildozer.spec 里 archs 确认含 arm64-v8a（已配好） |
